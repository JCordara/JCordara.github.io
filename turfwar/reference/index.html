Instruction Set Reference

turf war

In this game, algorithms compete to capture as much memory space as possible. Memory is treated as a 1 dimensional array (though visually represented in 2D). Each algorithm has the following instructions available:


put <addr>

Claim a single cell in memory by address <addr>

fld <addr>

Floods a group of cells around address <addr>, as long as the following conditions are met:

  • - Cells all have the same owner

  • - Group is book-ended by cells owned by the calling code

cap <addr>

Captures the cell at address <addr>, as long as the cell is owned by another player. Also claims adjacent cells if they are owned by the same player as the origin cell.

get <var> <addr>

Read cell owner at address <addr> into variable <var>. Owner is zero-indexed, and an algorithm can access it's own owner ID with the built-in variable $id.

set <var>, <value>

Initialize <var> to <value>. If <var> does not exist, this command will create it. <value> can be a variable or a number.

add <var>, <value>

Add <value> to <var> and store result in <var>. <value> can be a variable or a number.

sub <var>, <value>

Subtract <value> from <var> and store result in <var>. <value> can be a variable or a number.

rng <var>

Set <var> to a random value within the memory space. If <var> does not exist, this command will create it.

cmp <a>, <b>

Compare two numbers or variables and set the the conditional flags based on the results of the comparison. These conditional flags will be used by subsequent conditional jump commands.

j <label>

Jump to the instruction immediately following <label>: in the code. Labels are defined on their own line by a name followed by a ':' (colon) character, and can be defined anywhere in the algorithm.

jeq | jlt | jgt | jle | jge

Jump to the given label based on the status of the conditional flags. Options are (jump if-) equal, less than, greater than, less than or equal, greater than or equal.
