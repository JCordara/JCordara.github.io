Instruction Set Reference

turf war

In this game, algorithms compete to capture as much memory space as possible. Memory is treated as a 1 dimensional array (though visually represented in 2D). Each algorithm has the following instructions available:


put

Claim a single cell in memory by address

set

Initialize a variable to given value. If variable does not exist, this command will create it. Initial value can be another variable.

add/sub

Add a value to a variable or subtract a value from a variable. The value can be another variable.

rng

Set a variable to a random value within the memory space. If variable does not exist, this command will create it. Initial value can be another variable.

cmp

Compare two numbers or variables and set the the conditional flags based on the results of the comparison. These conditional flags will be used by subsequent conditional jump commands.

j

Jump to a label in the instructions. Labels are defined by a name followed by a ':' (colon) character, and can be defined anywhere in the algorithm.

jeq/jlt/jgt/jle/jge

Jump to the given label based on the status of the conditional flags. Options are (jump if-) equal, less than, greater than, less than or equal, greater than or equal.
