Some random projects

ches

A public chess board - anyone can move the pieces. Press R to reset. Featuring high effort MS Paint artwork. (Babylon.js, Typescript, Node backend)

tetris

A modified clone of raylib's Tetris example. Added features like CCW & 180 rotation, SRS rotation resolution, instant drop, shadow, 4-piece queue, hold, and general playability fixes (C, raylib)

turf war

Use an assembly-like instruction set to capture as much space as possible. (Typescript)
